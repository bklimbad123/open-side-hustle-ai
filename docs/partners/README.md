# Partner Integration Notes

These notes describe practical ways ReceiptLens could use partner tools. They
are integration plans, not claims that every service is already wired into the
application. The core app remains local-first; cloud services are opt-in.

- [Arduino](arduino.md): physical receipt-capture or status-display experiments
- [Backboard](backboard.md): terminal-oriented AI workflow experiments
- [Copilot](copilot.md): repository development and CI assistance
- [DigitalOcean](digitalocean.md): hosted API or GPU deployment
- [ElevenLabs](elevenlabs.md): optional spoken receipt summaries
- [Gemma](gemma.md): local open-weight extraction model
- [Mastra](mastra.md): orchestration and agent workflow experiments
- [MongoDB](mongodb.md): optional hosted job storage
- [Render](render.md): container-based demo deployment
- [Sentry](sentry.md): opt-in error monitoring
- [SerpApi](serpapi.md): optional vendor enrichment
- [TabPFN](tabpfn.md): tabular classification experiments
- [Temporal](temporal.md): durable long-running extraction workflows
- [Tinker](tinker.md): model experimentation and fine-tuning research
- [Tiger Data](tigerdata.md): optional PostgreSQL and vector-search extensions
